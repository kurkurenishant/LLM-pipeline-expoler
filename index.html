Educational Guide: NLP Tokenization & 3D Embeddings

1. What is Tokenization?

Computers and neural networks cannot process raw human text strings directly. Tokenization breaks unstructured text into atomic discrete units called Tokens (words, subwords, or characters).

In word-level tokenization, punctuation is removed and words are normalized to lowercase so that "Playing" and "playing" are recognized as the exact same token concept.

2. Vocabulary Builder & Numerical Token IDs

The Vocabulary is an indexed lookup dictionary containing every unique word seen in the corpus. Each word is mapped to a sequential integer Token ID:

"cat" → 0, "dog" → 1, "playing" → 2, "the" → 4 ...

When text is converted into numbers (e.g. [4, 0, 1, 2, 3, 4, 5, 1, 2]), it becomes an input tensor that machine learning models can compute with matrix operations.

3. High-Dimensional Word Embeddings in 3D Space

While integers represent identity, they do not convey meaning. Word Embeddings map each word to a point in a continuous geometric vector space where proximity represents semantic similarity.

In modern LLMs (BERT, GPT), embeddings span 768 to 4096 dimensions. In this application, words are projected into an illustrative 3D coordinate space $(X, Y, Z)$ using deterministic clustering and contextual co-occurrence, allowing you to physically rotate, zoom, and inspect relationships.

4. Cosine Similarity Formula

Cosine similarity measures the angle θ between two vectors:

cos(A, B) = (A · B) / (||A|| × ||B||) = (x_A x_B + y_A y_B + z_A z_B) / (||A|| × ||B||)
  • +1.0: Vectors point in the identical direction (maximum semantic similarity).
  • 0.0: Vectors are orthogonal (unrelated concepts).
  • -1.0: Vectors point in opposite directions.
